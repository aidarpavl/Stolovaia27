# 🍽️ Столовая школы Жас Дарын

Мектеп асханасына онлайн тапсырыс беру жүйесі.

## 🚀 Мүмкіндіктер

### 👨‍🎓 Оқушы режимі
- Класс енгізу (1-11 сыныптар)
- Апта таңдау (1-4 апта)
- Күн таңдау (Дүйсенбі–Жұма)
- Санат бойынша сүзу
- Тағамдарды себетке қосу
- Тапсырыс беру

### 👨‍🍳 Асханашы режимі
- Мәзірді өңдеу (кесте түрінде)
- Жаңа тағам қосу
- Тапсырыстарды қарау
- Есептерді шығару (тағам, сынып, күн, санат бойынша)

## 📁 Файлдар
- `app.py` — негізгі қосымша
- `menu.csv` — мәзір деректері
- `Orders.csv` — тапсырыстар деректері
- `requirements.txt` — тәуелділіктер

## 🛠️ Орнату

```bash
pip install -r requirements.txt
streamlit run app.py
